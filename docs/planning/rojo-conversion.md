# Rojo conversion notes

`src/` was generated by running Rojo 7.7's `rojo syncback` against an exported `steal-a-base.rbxlx`, replacing the original `rojo init` placeholder scaffold. This is how the original "Steal a Base" game became the working base for the [PC Repair Simulator overhaul](pc-repair-simulator-plan.md) — it's a reskin of the existing game, not a from-scratch build.

`default.project.json` maps each real DataModel service (Workspace, Lighting, ReplicatedStorage, ServerScriptService, ServerStorage, StarterGui, StarterPlayer, SoundService, Teams, Chat, ReplicatedFirst) to a `src/<Service>` folder, plus captures service-level properties/attributes that syncback can't express as files.

**Things to know:**
- The source `steal-a-base.rbxl`/`.rbxlx` files are gitignored and not meant to stay in the repo — they were only the syncback input.
- `Workspace/Map` had to fall back to a couple of `.rbxm` binaries instead of directories because of duplicate child names (case-insensitive collisions among `Part`/`ColorPart`/`Model`/`InvWall`). If editing that area of the map extensively, be aware those subtrees aren't diffable as plain text — you'll need to open them in Studio via the Rojo plugin.
- To pull further changes from a place file, sync the whole file to XML (`.rbxlx`) via Studio's Save As, then run `rojo syncback --input <file>.rbxlx default.project.json` from the repo root.
